# RESONANCE

Responsive single-page prototype for an immersive audiobook platform.

## Run locally

Serve the folder over HTTP:

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Included

- Responsive desktop and mobile layout
- Five optimized WebP portraits, correctly identified as Plato, Pushkin, Turgenev, Seneca, and Bunin
- Supplied 19.5-second MP3 integrated into the opening sound experience
- Timed cinematic text sequence, lightweight scroll reveals, progress indicator, hover motion, and ambient effects
- Interactive sound-layer demo using the Web Audio API
- Mood catalog, featured title, voices, and pricing
- Keyboard focus, reduced-motion support, semantic labels, and alt text
- Lightweight PWA manifest and offline cache
- No external libraries, fonts, trackers, or network dependencies
